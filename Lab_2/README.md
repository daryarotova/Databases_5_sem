# Лабораторная работа №2
## Разработка SQL-запросов и аналитических сценариев для реляционной базы данных

**Вариант предметной области №3:** Информационная система университета.

### Структура проекта
* `schema.sql` — создание структуры БД.
* `data.sql` — формирование содержательного набора данных.
* `dml.sql` — операции изменения данных.
* `queries.sql` — получение операционной информации, подзапросы.
* `cte.sql` — комплексный аналитический отчет с использованием CTE.
